# Обучение собственного PPO-LSTM

Три сида прошли по 3 000 000 переходов. На каждом сиде сохранены начальные веса (шаг 0), ранние веса после первого сбора и лучший чекпоинт по средней RMSE на 256 фиксированных валидационных эпизодах. При выборе чекпоинта падению присваивали ошибку 200 см.

| Сид | Ранний шаг | Первая валидация, шаг / RMSE (см) / падения | Лучшая, шаг / RMSE (см) / падения | Время обучения с валидацией, мин |
|---:|---:|---:|---:|---:|
| 0 | 8192 | 253952 / 21.26 / 0 | 3000000 / 2.31 / 0 | 36.4 |
| 1 | 8192 | 253952 / 53.45 / 6 | 2506752 / 2.53 / 0 | 36.5 |
| 2 | 8192 | 253952 / 54.66 / 12 | 2752512 / 2.27 / 0 | 36.6 |

Каждую пару весов и статистик нормализации загрузили и проверили получение действия. После обучения изменились веса выходных слоёв актора и критика. [Кривые валидации](validation.png) · [Чекпоинты и журналы](../../runs/native_defense/rppo_hover)
