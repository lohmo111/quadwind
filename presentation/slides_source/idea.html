Project idea: what does learned memory give?

PID

classic; memory = an error “piggy bank”, built by hand

PPO

no memory: sees only the current frame

PPO + ∫

the same piggy bank is fed to the network as input

RPPO

our method: the memory is learned

Same environment, same disturbances, same test episodes for all. We measure accuracy (cm), crashes (%) and the response to gusts and mass changes.

First validation result: RPPO holds the point with a median error of ≈ 2.5 cm and 0% crashes.

[Speaker A] So, the main question of the project: what does learned memory actually give us? We put four approaches side by side: PID with its hand-made piggy bank; PPO with no memory; PPO that gets the piggy bank as an input; and our RPPO, which learns its memory by itself. All of them fly in identical conditions. We measure accuracy, crashes and how they react to gusts. A first result is already in: RPPO holds the point with a median error of about 2.5 centimetres and not a single crash in validation. More in the next part. Thank you!
